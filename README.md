One fortune cookie line for a crypto trader who was just liquidated: an oracular stranger arrives bearing your fortune — and the stranger turns out to be the margin call, already inside your house. Rueful, warm, and one breath long.

## Run it

```sh
OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The program writes a single line (18 words, 104 characters) to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
